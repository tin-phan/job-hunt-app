Privacy policy

Last updated: 14 November 2026

job-hunt is a personal tool. Its only user is its owner, who signs in with the owner's own dedicated Gmail account.

What it accesses

  • Gmail, read-only (gmail.readonly): it reads job-alert emails from LinkedIn, Indeed and Google job alerts. It never sends, changes or deletes email.
  • Google Drive, its own files only (drive.file): it can see only files that it created itself.

What it keeps

From each job-alert email it keeps only the job details: job title, company, location, pay if shown, posting date and the job link, plus the email's ID so the same email is not read twice. It does not keep the email text.

Where the data goes

  • The job details are stored in the owner's private code repository.
  • A short list of jobs is sent to the owner's own Telegram chat.
  • Nothing is sold, shared with others or used for advertising.

Google API Services User Data Policy

job-hunt's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can remove job-hunt's access at any time at myaccount.google.com/permissions.

Contact

Use the support email shown on the Google sign-in screen for job-hunt.
